# Sugestão de 10 Cards para o Quadro Kanban (GitHub Projects)

Colunas sugeridas: **A Fazer** (`To Do`), **Em Progresso** (`In Progress`) e **Concluído** (`Done`).

1. `[Setup]` Configurar estrutura do repositório e `README.md` — *Concluído*
2. `[Modelagem]` Criar Diagrama de Casos de Uso e Diagrama de Classes — *Concluído*
3. `[Backend]` Implementar CRUD básico de tarefas (`src/task_manager.py`) — *Concluído*
4. `[Banco de Dados]` Migrar armazenamento em memória para SQLite (`data/techflow_tasks.db`) — *Concluído*
5. `[Testes]` Escrever testes unitários e de persistência (`tests/test_task_manager.py`) — *Concluído*
6. `[CI]` Configurar workflow do GitHub Actions (`.github/workflows/ci.yml`) — *Concluído*
7. `[Interface]` Desenvolver painel web em Flask (`src/app.py`) — *Em Progresso*
8. `[Mudança de Escopo]` Implementar painel e motivo de alerta para SLA crítico (`<= 4h` ou `Crítica`) — *Em Progresso*
9. `[Documentação]` Elaborar documento teórico com diagramas UML e prints comentados — *A Fazer*
10. `[Apresentação]` Gravar e publicar Vídeo Pitch (até 4 minutos) — *A Fazer*
